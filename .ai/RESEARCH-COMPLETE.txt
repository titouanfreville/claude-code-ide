KEY FINDING
================================================================================

Your reverse proxy is the trust boundary.

CC will route ALL traffic through ANTHROPIC_BASE_URL:
  - System prompt
  - User messages
  - Tool results
  - File contents
  - API key

At the proxy, you can:
  ✅ Redact secrets before forwarding
  ✅ Capture rate-limit headers
  ✅ Expose quota state to IDE
  ✅ Enforce quotas client-side

HARD BLOCKERS (All Solved)
================================================================================

1. Secret Redaction
   Why not hooks? PostToolUse fires AFTER output captured
   Solution: Reverse proxy intercepts request JSON

2. Rate-Limit Visibility
   Why not CC hooks? No hook exposure, no statusline API
   Solution: Reverse proxy captures HTTP response headers

3. Tool Steering
   Why not CC settings? Model doesn't know tool origin
   Solution: Deny built-in + CLAUDE.md guidance

ARCHITECTURE
================================================================================

CC Session
  ├─ env ANTHROPIC_BASE_URL=http://127.0.0.1:9999
  └─ env HTTPS_PROXY=http://127.0.0.1:9999
       ↓
Your Reverse Proxy
  ├─ Parse request JSON
  ├─ Redact secrets (regex patterns)
  ├─ Forward to api.anthropic.com
  ├─ Capture response headers
  ├─ Write quota state file
  └─ Return response
       ↓
IDE (MoonlightCode)
  └─ Polls quota state (5-10s)
      ├─ Display rate-limit headroom
      ├─ Queue/delay sessions if needed
      └─ Log redaction events
