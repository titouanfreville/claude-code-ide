# MoonlightCode

Governance and review for Claude Code sessions. This is an extension pack — it
installs the MoonlightCode extensions together:

- **Core** — shared backend connection and session state
- **Status** — is anything actually gated?
- **Session Control** — adopt, phase, start governed sessions
- **AI Review** — review what the agent changed, and send it back
- **Agentic Support** — answer a plan proposal or a held action before it times out
